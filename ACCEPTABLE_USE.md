# Acceptable use

This project exists for authorized security testing, defensive validation and
reproducible research.

## You may

- run it against systems you own;
- run it against systems for which you have explicit, written permission from
  the owner;
- use it in an isolated laboratory;
- use the profiles, calibration tools and documentation to harden systems.

## You may not

- scan, exploit or disrupt third-party infrastructure;
- build or distribute target lists or mass-exploitation tooling;
- use the worker-saturation/pinner modes against systems you do not own;
- publish data obtained from systems you do not own;
- remove or hide the authorized-use notice from redistributed copies.

## Disclosure

If you find a new affected build or a new issue in PHP, prefer coordinated
disclosure with the PHP security team and the affected vendor.
